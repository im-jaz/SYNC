# SYNC

A modern, responsive portfolio website designed to showcase creative projects and client testimonials in a clean and elegant layout.

## Overview

This project is a collaborative portfolio website built to demonstrate our front-end development skills and showcase selected projects in an engaging, visually polished way.

The website combines a warm white and cream color palette with a minimalist luxury-inspired design. It includes a transparent navigation bar, a hero section, interactive project cards, testimonials, and a contact section.

## Features

* Responsive navigation bar
* Hero section with background imagery
* Project showcase section
* Project cards featuring:

  * Project image
  * Project description
  * Technologies used
  * Client-style testimonial
* Responsive layout for different screen sizes
* Contact section with email and GitHub links
* Interactive elements powered by JavaScript
* Clean and reusable HTML and CSS structure

## Technologies Used

* **HTML5** — Structure and content of the website
* **CSS3** — Styling, layout, responsiveness, and visual design
* **JavaScript** — Dynamic project content and interactive functionality

## Design

The website was designed with a minimalist and sophisticated aesthetic. The white and cream color palette creates a warm, elegant appearance while the transparent elements and large background imagery give the site a modern feel.

The project cards were designed to present each project alongside its corresponding testimonial, making the portfolio more visually engaging than a traditional project grid.

## JavaScript

JavaScript is used to dynamically handle project information and generate project content on the page. This allows multiple projects to be managed from a JavaScript data structure rather than manually repeating the same HTML for every project.

The project information is stored using objects inside an array, and JavaScript loops through the data to render the projects dynamically on the page.

## Responsiveness

The website includes responsive CSS to ensure that the layout adapts to smaller screens such as tablets and mobile devices.

Elements such as navigation links, project cards, spacing, and typography adjust at different screen sizes to maintain a usable and visually consistent experience.

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone git@github.com:im-jaz/SYNC.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Alternatively, you can use **VS Code Live Server** to preview the website while developing.
